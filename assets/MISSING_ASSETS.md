## 需要補齊

下列尺寸是重新製作時的建議值；原版尺寸、符號數量與動畫結構尚待資源清單驗證。

| 名稱 | 建議尺寸／格式 | 風格與用途 |
| --- | --- | --- |
| 三款遊戲各自背景 | 1000 × 1780 PNG/WebP | 對應原遊戲直式場景；需原檔或參考圖 |
| 各款角色與標題 | 依原始圖集；替代版可用 1024 × 1024 透明 PNG | 象財神、老虎財神、阿拉丁主題 |
| 各款完整轉輪符號 | 每符號建議 256 × 256 透明 PNG | 包含普通、Wild、Scatter 與特殊符號；精確清單待確認 |
| 轉輪框與操作按鈕 | 原尺寸 PNG 與 atlas JSON | 旋轉、加減注、快速、自動、設定等狀態 |
| 角色與中獎動畫 | PNG spritesheet / atlas JSON / 原始動畫資料 | 動作、特效、免費遊戲與獎勵演出 |
| 音效與背景音樂 | OGG/MP3/WAV | 非圖像；需要對應事件與音量資訊 |
| 字型與資源設定 | WOFF2/TTF/FNT、JSON | 若原版渲染需要，連同載入路徑一起提供 |

## 優先補件方式

提供完整遊戲 build／assets 目錄、atlas JSON、相關 JS 分包及設定檔，或瀏覽器實際遊玩時匯出的「包含回應內容」HAR。HAR 可能含登入憑證，分享前請移除私人憑證，但保留靜態資源回應。只有 HTML 或截圖不足以還原原版動畫與邏輯。

伺服器回應已獲准使用假資料；仍須根據實際請求格式確認初始化、餘額、下注、轉輪結果、免費遊戲與錯誤回應。假資料不等同原版機率或賠付模型。

## 若選擇重新生成 PNG

需使用者明確同意近似版本後才開始。以下 prompt 可直接用於圖像生成工具，不使用 SVG、Canvas 或 Phaser Graphics：

- 背景：直式手機遊戲背景，1000x1780，主題為［中國風象財神／中國風老虎財神／阿拉丁神燈宮殿］，精緻卡通 3D 插畫，華麗金色裝飾，中央留出清晰轉輪區，下方留出操作區，無文字、無標誌，PNG。
- 符號：單一［待指定符號］，256x256，精緻卡通 3D 風格，統一正面視角與柔和光源，輪廓清晰，置中，透明背景，無文字、無標誌，PNG。每個符號分別生成。
- 角色：［象財神／老虎財神／阿拉丁精靈］，1024x1024，精緻卡通 3D 插畫，完整角色，姿勢清楚，透明背景，無文字、無標誌，PNG。

可尋找替代素材：https://kenney.nl/assets 、https://itch.io/game-assets/free 、https://opengameart.org/ 。使用前需確認各項素材授權及風格是否符合需求。
