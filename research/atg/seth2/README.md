# 戰神賽特2：本機假後端模擬版

2026-10-23，原版 Cocos 3.7.2 客戶端已接上隔離的本機假後端。支援合成普通回合、免費遊戲與覺醒樣本流程；不是原站機率或完整後端的還原。

## 使用

執行 `python3 research/atg/seth2/local_server.py`，開啟 http://127.0.0.1:18767/ 。也已接入專案的 `python3 start-local.py` 本機入口。

每次從根網址開啟會建立獨立的 10,000 虛擬餘額。保留帶有 local token 的網址可繼續同一工作階段。餘額、設定、待結算回合及歷史保存在忽略版控的 local-state.json，伺服器重啟後仍可讀取。點「開始遊戲」，以中間轉動按鈕遊玩，可用加減調整金額。大獎彈窗可點擊跳過數字演出；免費遊戲結束的大獎可按空白鍵確認返回。一般啟動（發布預設）音樂 50%、音效 80%；開發請使用 `python3 research/atg/seth2/local_server.py --mute` 或 `python3 start-local.py --mute`，只對開發回應套用音量 0，不會把靜音寫回發布設定。舊版開發靜音預設會一次遷移成正常音量；之後使用者自行選擇的音量會保留。

左上角「本機假資料 · 模擬設定」可設定一般回合中獎機率 0–100%、中獎金額相對下注的倍數，以及下一局的特殊流程。預設為 30%、2 倍。一般回合的預期派彩率為機率乘倍數；這不是原版 RTP，免費／覺醒／購買獎勵另計。覺醒沿用公開出貨 spin4 的鎖定、分裂與倍率樣本，按下注縮放並串接免費回合；此樣本獎金不受一般回合中獎機率控制。

## 已驗證與未完成

- 原版介紹頁、主畫面、普通轉動、扣虛擬點數、連消與倍率演出。
- 已驗證 `initial → spin → closeSpin`；修正快速／自動模式預先請求下一局與 forceClose 的協定適配。快速自動 10 局、0% 中獎，畫面及後端餘額皆為 10,000 → 9,990；接著改為 100%、2 倍，完成回合後為 9,991。
- 免費遊戲及覺醒樣本已走到結算返回主畫面；剩餘次數修正後的覺醒測試由餘額 9,900 開始，虛擬下注 1、派彩 2,675，畫面與後端餘額皆為 12,574。這是公開出貨樣本串接合成回合，不代表所有原版覺醒組合已還原。
- 七項單元測試通過：金額守恆、冪等結算、預取及 forceClose、錯誤下注、工作階段隔離、待結算資料恢復、0%／100% 邊界、免費回合計數、靜音初始值、歷史摘要，以及購買後續接不重複扣款。完整瀏覽器重載恢復尚待驗證。
- MINI 彩金動畫可確認返回；寶箱合成回合可結算返回。購買免費遊戲在瀏覽器完成 15 次，餘額 10,000 → 9,900，只扣一次 100；注單及歷史頁顯示下注 100、獲利 -100、筆數 1。細節見 entry-verification.json。原版彩金池、完整機台大廳、排名／回放、日期篩選與原版抽樣機率未還原或未驗證。
- 啟動 definition 是依照客戶端讀取欄位建構的假資料，不是擷取的原站初始化回應；獎金說明與設定不代表原版數值。

## 來源與分析

使用者完成有春手機驗證後，實際啟動 `golden-seth`，啟動參數版本 `261006`；遊戲畫面版本 `gv1.1.5_8 / sv1.1.3_3`。有春內嵌框停在載入時，同一個啟動網址獨立分頁成功進入介紹與選台畫面。未操作原站下注。

已取得原版啟動 HTML、主程式、g1005 遊戲本體，以及 `slotFramework/14ee78206168302dd5e294aaa97f5c0b21de68f5/` 共用框架。`mirror/` 目前約 3,007 個檔案、141 MB，`asset-manifest.json` 保存大小與 SHA-256。這個清單的完整性以所下載檔案為界，不能當作全遊戲資源已齊全的證明。

原程式公開附帶 `script/data/testSpin/spin1..8` 與五組 closeSpin 範例，這些不是使用者帳號實際回合。保留原始檔案；本機讀取時將樣本 token 改成本機值，不傳回原站。

`tools/decode-framework.cjs` 只在有時限的隔離 VM 中執行字串表、解碼函式和字串表旋轉，不執行遊戲工廠或啟動程式。`extracted/` 保存可追讀的 System.register 模組。`rea-summary.json` 指向 REA 6.7.0 的靜態分析證據，該次分析範圍是初次取得的程式樹，後續追加的素材不在該證據中。靜態分析不等於觀察到執行成功。

## 本機變體

- 原版圖檔、字型、Spine、音樂與 Cocos renderer；沒有用程式生成替代美術。
- Socket.IO 載入路徑在本機由 `local-socket.js` 適配為 loopback JSON；不連原站 socket。
- 共用框架只將 CryptoTool 模組替換成本機明文適配，因為不使用原站加密協定與憑證。原始下載檔案不變。
- 以 CSP 限制 connect/img/media/script 至本機及必要的 blob/data。這不是完整的網路封包攔截驗證。
- 本機持有虛擬餘額與待結算回合，closeSpin 依 spinId 冪等派彩，支援同工作階段預取下一局。local-state.json 為本機狀態快照，不應發布。

```sh
python3 research/atg/seth2/test_backend.py
```
